# Проектная работа Mesto

Проект «Mesto» — интерактивная страница с профилем, карточками мест и интеграцией с API.

## Ссылка на проект

[Открыть Mesto](https://Fel1da.github.io/mesto-project-ff/)

##  Стек

- HTML, CSS, JavaScript
- Webpack, PostCSS
- REST API (`https://nomoreparties.co/v1/`)

##  Команды

- npm install     - установить зависимости
- npm run dev     - запустить dev-сервер на http://localhost:8080
- npm run build   - собрать прод-версию в папку dist/
- npm run deploy  - собрать и задеплоить на GitHub Pages
